### Minecraft: PlayStation 4 Edition - Preservation Archive
This repository is a centralized web directory for the digital preservation of Minecraft: PS4 Edition content. It provides an organized index linking directly to fpkg base games, updates, backports, and DLC packs hosted on the Internet Archive. 

### How to Choose and Download Content

1. **Select the Region:** Click the tabs at the top of the site to match your game's region: Europe (CUSA00265), United States (CUSA00744), or Japan (CUSA00283).
2. **Locate the File Type:** Scroll to find Base Games, chronological Updates, custom Backports for older firmwares, or DLC Packs (skins, textures, mash-ups).
3. **Download:** Click Info to check file details and game versions, or click Download to save the file directly to your local storage via your browser. All provided files are Fake PKGs (FPKGs) compatible with jailbroken consoles.
